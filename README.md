# Car Cost — 新車・中古車の総保有コスト比較

GitHub Pages向けの静的Webアプリ。車種別にガソリン・HEV・PHEVの新車と中古車を比較し、棒グラフと計算根拠を表示します。

## ファイル
- `index.html` — iPhone/PC対応の比較UI、グラフ、計算ロジック
- `data/vehicles.json` — 車種・パワートレイン・想定価格・参照先
- `data/assumptions.json` — 中古価格率・維持費・売却予測・補助金の仮定

## GitHub Pages
Repository > Settings > Pages > Build and deployment > Deploy from a branch > `main` / `/(root)` > Save。

公開後の想定URL: https://kameusagiyahoo.github.io/car_cost/

ローカル動作確認: `python3 -m http.server 8000` を実行して http://localhost:8000/ を開く。ファイルを直接開くとブラウザの制約でJSONを取得できない場合があります。

## データの信頼性
**現時点の価格・燃費・中古車価格率・補助金・将来売却価格は比較用の仮定値です。実売価格・買取実績の引用済みデータではありません。** メーカーへの一般リンクを価格の根拠として扱わないでください。

実データに置き換える際は、グレード、登録年、走行距離、支払総額、情報源URL、取得日時、サンプル数、集計方法、適用地域を記録してください。買取価格と中古車の販売価格を混同しないこと。外部サイトの自動収集は利用規約と取得許諾を確認してから行ってください。

## 2026-10-31 公式価格の部分導入
シエンタ Z（2WD・7人乗り）のガソリン車・HEV車、プリウス PHEV Z（2WD）の車両本体価格と公表燃費をメーカー／正規販売店ページに基づき登録しました。画面の「購入価格の根拠」から参照できます。これら以外の価格・燃費は依然として仮定値です。

**重要:** 公式の車両本体価格は支払総額ではありません。中古価格は公式掲載価格から仮の残価率を乗じているだけで、実在する中古車の販売事例ではありません。売却予測も未検証です。プリウスHEVとPHEVは現段階ではグレードが揃っていません。今後、同一グレード・同一駆動方式の価格整合を進めます。

## 中古車掲載実例（2026-10-31）
`data/used-listings.json` にシエンタ HEV Z 2件、プリウス PHEV Z 1件の支払総額・年式・走行距離・出典URLを登録。選択中古車年式と一致し、想定走行距離±15,000kmの実例がある場合のみ、支払総額の中央値を購入価格に採用。実例がなければ従来の仮定残価率にフォールバック。サンプル数は少なく、乗車定員・オプション・地域・駆動方式の厳密な一致は未検証。将来売却額は引き続きモデル推定。掲載終了に備えてURLと確認日を記録。

## 乗車定員・検証条件の厳格化
2026-10-31: 中古車の採用条件に乗車定員（シエンタ7人、プリウス5人）と検証日時の存在を追加。年式・グレード・2WD・修復歴なし・走行距離±15,000kmも必須。該当3件以上で中央値を採用。装備・地域差、掲載消滅、重複掲載、価格の変動はなお課題。プリウスPHEV Zの2023年式・33,000km・357.5万円の掲載例を追加。データの個別URLを参照してください。

## 売却価格の買取実績アンカー（2026-10-31）
`data/resale-observations.json` に2023年式シエンタHEV Z（3件）とプリウスPHEV Z（4件）の買取査定実績を登録。グレードと車種が一致する場合は買取査定中央値を起点に、年12%減価・基準走行距離超過1万kmにつき2%減額する**仮定のシナリオ**で将来売却額を推計。該当実績がない車種は従来のモデル予測。これは未来の売却保証額ではなく、年12%の仮定は実証的に校正されていません。3年より短い車齢には外挿せず従来予測を使用。個別の駆動方式・装備・乗車定員・査定条件は未確認です。

## 年式別買取相場と売却額の幅（2026-10-31）
`data/resale-age-series.json` にシエンタ HEV Z（7人乗り）の2022〜2026年式の横断面買取相場を出典付きで追加。シエンタとプリウスPHEVの既存買取実績アンカーに対し、年6%減価（売却額上限）〜年18%減価（下限）の**感度分析**を売却額・総保有コストに表示します。中心値は従来の年12%減価モデルを継続。これは統計的な信頼区間ではなく、複数年式データから推定された回帰係数でもありません。年式差は走行距離・グレード・装備・相場の構成差を含むため、単純な年次減価率としては使用していません。3年未満の年式には範囲を外挿しません。

## 個別査定データの品質ゲート
現時点の個別査定記録はシエンタ3件・プリウス4件で、査定額と走行距離は記録されています。しかし、駆動方式・乗車定員・車両状態の確認が不足し、同一年式の記録だけでは車齢と走行距離の係数を同時推定できません。重複掲載の確認も必要です。このため個別査定記録は回帰の学習には採用しません。将来の採用条件は、出典URL・査定日・年式・グレード・駆動方式・走行距離・査定額・車両状態の確認と重複排除、異なる車齢を含む十分なサンプル、時点を分けた予測検証です。

## データ更新時の自動検証
`python3 scripts/validate_data.py` でJSONデータの整合性と出典メタデータを検査できます。`.github/workflows/validate-data.yml` により、dataディレクトリ・検証スクリプト・ワークフローの変更時にGitHub Actionsで自動実行します。エラーはジョブ失敗、仕様不足・重複URLの疑いは警告です。警告が残っていてもジョブは成功するため、結果ログを確認してください。外部掲載URLの実在性や価格の真偽までは検証していません。
